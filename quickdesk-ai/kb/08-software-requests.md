# Software Installation Requests

## Company-Approved Software

A catalogue of pre-approved software is available on the IT portal at `it.company.internal/software`. These can be self-installed via **Software Center** (Windows) or **Self Service** (Mac) without raising a ticket.

Common pre-approved tools include: VS Code, Slack, Zoom, Chrome, Firefox, 1Password, Docker Desktop, Postman.

## Requesting New Software

If the software you need is not in the catalogue:
1. Submit a helpdesk ticket with:
   - Software name and version.
   - Business justification (why you need it).
   - Cost (if paid — include a link to pricing).
   - Your manager's name for approval.
2. IT will review for security and licensing compliance.
3. Approval typically takes **3–5 business days**.

## Paid Software

Paid software requires manager approval and Finance sign-off if over $100/year. Include a cost estimate in your ticket.

## Installing Software Yourself

Do not install unapproved software on company devices. This violates the Acceptable Use Policy and may trigger a security alert. If you need something urgently, contact IT — we can often fast-track approvals.

## Removing Software

If you no longer need a licensed application, submit a ticket to have it removed so the licence can be reallocated.
