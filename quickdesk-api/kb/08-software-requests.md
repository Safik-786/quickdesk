# Commercial Software Request and Licensing Policy

## 1. Overview
To ensure software compliance and manage SaaS sprawl, all commercial software installations and cloud subscriptions must be approved and procured centrally by the IT Procurement team.

## 2. Approved Software Catalog
Employees can self-serve approved, pre-licensed software via the **Company Portal (Windows)** or **Jamf Self Service (macOS)** app. No IT ticket is required for software in this catalog. Examples include:
- Visual Studio Code
- Slack
- Firefox
- Docker Desktop

## 3. Requesting Unlisted Software
If a required application is not in the Self Service portal:
1. Check if a free, approved alternative already exists.
2. If not, submit a **Software Request** ticket via the IT Helpdesk.
3. Provide a business justification and the associated cost.
4. Provide the vendor's security documentation (SOC2 report) if it is a cloud-based SaaS tool.

## 4. Approval Workflow
- **Free/Open Source Software**: Requires a rapid security review by InfoSec to ensure no malicious code or restrictive licensing (e.g., AGPL in proprietary codebases).
- **Paid Software (< $500/yr)**: Requires direct manager approval.
- **Paid Software (> $500/yr)**: Requires Department Head financial approval and formal IT Procurement review.

## 5. Shadow IT and Prohibited Software
Employees are strictly prohibited from purchasing software with a corporate credit card and expensing it without prior IT approval. Unauthorized software (Shadow IT) will be actively blocked by endpoint protection. File sharing clients (BitTorrent, eMule), cryptocurrency miners, and unapproved remote access tools (TeamViewer, AnyDesk) are strictly blacklisted.
