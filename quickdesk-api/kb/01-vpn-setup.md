# Remote VPN Access Setup

All remote employees must use the Cisco AnyConnect VPN client to access internal company resources.

To install the VPN:
1. Navigate to `vpn.company.internal` and download the installer for your OS.
2. Install the application and restart your computer.
3. Open Cisco AnyConnect and enter the gateway server: `gateway.company.internal`.
4. Log in using your standard Active Directory credentials and approve the Duo 2FA push notification on your mobile device.

If you receive an "Access Denied" error, please submit an IT ticket so an administrator can manually add you to the VPN security group.
