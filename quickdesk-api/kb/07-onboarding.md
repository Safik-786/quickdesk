# Employee Onboarding Process

When a new employee is hired, HR will automatically generate an Onboarding Ticket 7 days prior to their start date.

IT is responsible for:
1. Creating the Active Directory account and email address.
2. Provisioning the requested hardware (laptop, monitor, accessories).
3. Shipping the hardware if the employee is remote (must be shipped 3 days prior to start date).

If the hiring manager needs specific software installed on the new hire's machine, they must add a comment to the Onboarding Ticket at least 48 hours before the start date.
